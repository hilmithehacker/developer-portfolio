## 🚀 Getting Started

### 1. Installation
```bash
git clone https://github.com/hilmithehacker/developer-portfolio.git
cd developer-portfolio
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
